# Flowbase Theme

## Direction
Flowbase should feel fresh, cozy, modern, and clean. The UI is a working productivity surface, so it should stay calm and scannable while still using lively color accents.

## Palette
- App background: soft mint, `#f2fbf6`
- Surfaces: warm white with subtle transparency
- Primary text: deep slate
- Muted text: cool slate gray
- Borders: soft blue-gray
- Accent colors: sky, mint, coral, amber, violet, fuchsia, emerald

## Sidebar
- Expanded width: `248px`
- Collapsed width: `76px`
- Menu rows: compact `32px` height
- Group labels: small uppercase labels with muted slate color
- Icons: Lucide icons, colorful per destination
- Collapsed state: icon-only navigation with labels hidden but titles and accessible labels preserved

## Shape And Density
- Use `8px` radius for cards and controls.
- Keep menu items compact and grouped.
- Avoid nested cards.
- Use light borders and soft shadows only where they help hierarchy.

## Interaction
- Sidebar width transitions smoothly.
- Active navigation uses dark slate fill with a bright icon accent.
- Hover states should be quiet: pale slate backgrounds and stronger text.
- Buttons should use icon + text for commands and icon-only for sidebar collapse.

## Avoid
- Heavy dark boilerplate styling.
- Dull beige-heavy cozy palettes.
- One-note purple or blue themes.
- Oversized marketing sections on app screens.
